# Коллекция Postman для тестирования REST API проекта Portfo 2.

## Коллекция

Содержит запросы, организованные по функциональным областям, а также автоматизированные проверки основных сценариев.

### Функциональные области

* **Authorization** — авторизация пользователя;
* **Refresh Token** — обновление access-токена;
* **Registration** — регистрация пользователей;
* **Exploratory Testing** — исследовательское тестирование API и проверка граничных и некорректных значений.

## Автоматизированные проверки

Postman-тесты проверяют:

* HTTP-статус ответа;
* Content-Type;
* наличие обязательных полей;
* типы и значения данных в ответе;
* наличие и непустое значение токенов;
* корректность обновления access-токена;
* использование актуального access-токена в авторизованных запросах.

Токены и другие тестовые данные передаются через переменные Postman.

## Переменные окружения

Для работы коллекции используется окружение `Portfo 2 — QA Practice`.

Основные переменные:

* `base_url` — базовый URL API;
* `email_auth` — email тестового пользователя для авторизации;
* `password_auth` — пароль тестового пользователя;
* `registration_email` — email, генерируемый для сценариев регистрации;
* `access_token` — access-токен, сохраняемый после авторизации;
* `refresh_token` — refresh-токен, сохраняемый после авторизации.

Токены `access_token` и `refresh_token` получают значения во время выполнения запросов и не содержат постоянных значений в экспортированном окружении.

## Служебный запрос

В коллекции присутствует запрос `[Служебный] Регистрация тестового пользователя`.

Он используется для первоначального создания постоянной тестовой учётной записи, которая затем применяется в сценариях авторизации.

[Служебный] Регистрация пользователя с минимальным паролем

Используется для создания тестовой учётной записи с паролем минимальной допустимой длины. Учётная запись используется в тест-кейсе авторизации с паролем длиной 1 символ.

Служебные запросы не предназначены для регулярного запуска вместе с основным набором тестов, так как используются для первоначального создания тестовых данных.

## Запуск

Для работы с коллекцией необходимо импортировать в Postman:

1. коллекцию [`Portfo 2 — QA_Practical.postman_collection.json`](./collections/Portfo%202%20%E2%80%94%20QA_Practical.postman_collection.json);
2. окружение [`Portfo 2 — QA Practice.postman_environment.json`](./environments/Portfo%202%20%E2%80%94%20QA%20Practice.postman_environment.json).

После импорта необходимо выбрать окружение `Portfo 2 — QA Practice`.

Основной сценарий начинается с авторизации. После успешного выполнения запроса токены сохраняются в переменные окружения и используются последующими авторизованными запросами.
