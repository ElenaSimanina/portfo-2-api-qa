# Portfo 2 — API QA

Практический проект по функциональному и исследовательскому тестированию REST API приложения Portfo 2.

## О проекте

Цель проекта — проверка корректности работы REST API, анализ обработки входных данных и выявление несоответствий требованиям API.

В рамках проекта выполнены:
- анализ API по Swagger;
- разработка тест-кейсов;
- позитивное и негативное тестирование;
- проверка API-запросов в Postman;
- автоматизация проверок основных сценариев с помощью Postman Tests;
- исследовательское тестирование;
- документирование результатов и оформление обнаруженного дефекта.

## Область тестирования

- Авторизация пользователей.
- Регистрация пользователей.
- Получение реферального хэша `invite_hash`.
- Получение данных профиля пользователя.
- Обновление access-токена с помощью refresh-токена.
- Обработка некорректных и граничных значений входных данных.

## Инструменты

- **Postman** — отправка API-запросов и автоматизированные проверки.
- **Swagger** — анализ документации API.
- **Excel** — оформление тест-кейсов и баг-репортов.
- **Git / GitHub** — управление версиями и хранение проекта.

## Выявленные дефекты

В ходе тестирования обнаружен и задокументирован дефект **BUG-001**: API принимает числовое значение `invite_hash` при регистрации, хотя ожидается строковый тип данных.

Описание дефекта находится в `bug-reports/`.
