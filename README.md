# Portfo 2 — API QA

Практический проект по тестированию REST API приложения Portfo 2.

## О проекте

Проект посвящён функциональному и исследовательскому тестированию REST API Portfo 2.

В рамках проекта выполняется:

- анализ API по Swagger;
- разработка тест-кейсов;
- позитивное и негативное тестирование;
- проверка API-запросов в Postman;
- документирование результатов тестирования;
- фиксация обнаруженных дефектов.

## Инструменты

- Postman
- Swagger
- REST API
- Git / GitHub
- Excel

## Покрытые области

- Авторизация
- Refresh Token
- Регистрация пользователя
- Исследовательское тестирование
